# Jellyfin Docker Deployment & Lifecycle Management

یک پکیج کامل، خودکفا و هوشمند برای راه‌اندازی، مدیریت، پشتیبان‌گیری و اتوماسیون سخت‌افزاری Jellyfin روی لینوکس (Omarchy / Arch).

---

## 📁 ساختار پوشه (Structure)

```text
├── docker-compose.yml       # تعریف سرویس کانتینر Jellyfin و نگاشت‌های سخت‌افزاری/دایرکتوری
├── jellyfin-setup.sh        # اسکریپت جامع تعاملی و ابزار CLI مدیریت کانتینر، هارد و گارد Udev

├── PROXY_GUIDE.md           # راهنمای تنظیم پروکسی میزبان برای دانلود متادیتا/پوسترها
└── README.md                # همین مستند
```

## ⚡ اتوماسیون لایف‌سایکل و گارد سخت‌افزاری (Udev Guard)

کانتینر بدون وابستگی به `restart: unless-stopped` مدیریت می‌شود تا در صورت نبود هارد، حافظه موقت سیستم آلوده نشود:
- **اتصال هارد (`TUF_Data`):** با اتصال فیزیکی کابل، گارد Udev پس از تأیید مانت شدن پارتیشن، به طور خودکار کانتینر Jellyfin را بالا می‌آورد.
- **قطع کابل هارد:** بلافاصله کانتینر متوقف شده و مسیرهای موقت پاکسازی می‌شوند تا از قفل شدن فایل‌سیستم یا بروز خطای تغییر نام مانت‌پوینت (`TUF_Data1`) جلوگیری شود.
- **خروج ایمن نرم‌افزاری (Safe Eject):** ویجت نوار وظیفه قبل از آن‌مانت، کانتینر را به شکل تمیز (`jellyfin-setup.sh stop`) خاموش می‌کند.
- **استاپ دستی:** در زمان اتصال هارد، کاربر می‌تواند هر زمان با دستور `jellyfin stop` سرور را خاموش کند بدون اینکه Udev دخالتی کند.

## 🚀 روش راه‌اندازی و استفاده (Quick Start)

با تعریف alias در Fish، از هر کجای ترمینال می‌توانید مستقیماً از دستور `jellyfin` استفاده کنید:

```fish
jellyfin
```

یا مستقیماً با فراخوانی اسکریپت:
```bash
./jellyfin-setup.sh
```

## 🧰 دستورات خط فرمان (CLI Usage)

| دستور | عملکرد |
|---|---|
| `jellyfin` / `jellyfin menu` | ورود به منوی تعاملی شماره‌دار |
| `jellyfin start` یا `--auto` | بررسی پیش‌نیازها و راه‌اندازی کانتینر Jellyfin |
| `jellyfin stop` | متوقف کردن کانتینر Jellyfin |
| `jellyfin restart` | راه‌اندازی مجدد کانتینر |
| `jellyfin status` | نمایش وضعیت کانتینر، مانت هارد مدیا و گارد Udev |
| `jellyfin logs` | مشاهده لاگ‌های زنده کانتینر |
| `jellyfin mount` | مانت دستی پارتیشن هارد TUF_Data |
| `jellyfin save` | تهیه نسخه پشتیبان از ایمیج داکر روی هارد اکسترنال |
| `jellyfin load` | بارگذاری مجدد ایمیج از فایل پشتیبان هارد |
| `jellyfin guard-install` | نصب/بروزرسانی گارد هوشمند سخت‌افزاری Udev |
| `jellyfin guard-remove` | حذف قوانین و اسکریپت گارد Udev |
| `jellyfin --help` | مشاهده راهنمای سریع دستورات |
