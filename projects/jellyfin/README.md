## 🚀 روش راه‌اندازی در توزیع جدید (Quick Start)

تنها کاری که بعد از نصب Docker در توزیع جدید باید انجام دهید:

```bash
./setup.sh
```

### این اسکریپت چه کارهایی انجام می‌دهد؟
1. **بررسی داکر:** بررسی اجرا بودن سرویس Docker و دسترسی کاربر.
2. **بررسی هارد اینترنال مدیا (`/mnt/ssd`):** در صورت مانت نبودن، با تایید شما دیسک را به `/mnt/ssd` مانت کرده و رکورد آن را در `/etc/fstab` ثبت دائمی می‌کند.
3. **هماهنگی خودکار GPU:** شناسایی خودکار GID گروه‌های `render` و `video` متناسب با توزیع فعلی برای شتاب‌دهی سخت‌افزاری (Hardware Acceleration).
4. **لود آفلاین ایمیج:** شناسایی خودکار ایمیج بکاپ از هارد اکسترنال (`/run/media/unreal/TUF_NTFS/.../jellyfin-latest.tar`) و بارگذاری سریع بدون نیاز به دانلود مجدد.
5. **بررسی پروکسی:** بررسی وضعیت پورت `10808` برای اسکرپرها.
6. **اجرای سرویس:** اجرای کانتینر با `docker compose up -d` و نمایش لینک‌های دسترسی محلی و تحت شبکه.

## 🧰 دستورات مستقیم و میان‌برها (CLI Usage)

علاوه بر منوی تعاملی، می‌توانید از سوئیچ‌های زیر نیز مستقیماً استفاده کنید:

| دستور | عملکرد |
|---|---|
| `./setup.sh` | اجرای جادوگر بررسی گام‌به‌گام به همراه منوی مدیریتی |
| `./setup.sh --auto` | اجرای خودکار مراحل و بالا آوردن سرویس |
| `./setup.sh save` | تهیه نسخه پشتیبان از ایمیج داکر روی هارد اکسترنال |
| `./setup.sh load` | بارگذاری مجدد ایمیج از هارد اکسترنال |
| `./setup.sh mount` | مانت هارد SSD و تنظیم fstab |
| `./setup.sh logs` | مشاهده لاگ‌های زنده کانتینر |
